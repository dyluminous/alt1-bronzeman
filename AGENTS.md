# Bronzeman — Alt1 RuneScape inventory tracker

Build: `npm run build` — webpack bundles into `dist/main.js`

## Directory structure

```
src/
  index.ts              Entry — bootstrap + Bronzeman.* re-exports for HTML onclick
  bootstrap.ts          App initialisation after DOM ready
  core.ts               Shared state, capture helpers, notifications, log, escHtml
  version.ts            Build number (auto-generated by prebuild)
  types/
    index.ts            All shared interfaces / type definitions
    fonts.d.ts          Alt1 font module declarations
    png.d.ts            PNG module declaration
  utils/
    hash.ts             Interior-hash computation (hashInterior, lowerHalfOf, nibbleTolerantMatch)
    helpers.ts          Pure shared helpers (readPixel, rgbMatch, rgbNear, hashChecksum, formatElapsed)
  classes/
    inventory.ts        Inventory class — grid state, slot access, singleton `inventory`
    inventory-slot.ts   InventorySlot class — geometry + per-slot item checks
    slot-animation.ts   SlotLoadingAnimation class — gold comet-ring border animation
  services/
    inventory-detect.ts Pure grid detection (fingerprints, measureGapToSlot2, countColumns, detectInventoryGrid)
    data.ts             UnlockStore — IndexedDB + in-memory unlock persistence
    capture.ts          Auto-capture lifecycle + retry loop
    slot-scan.ts        SlotScanner — monitors slot contents for appeared/removed/changed/moved events
    slot-hover.ts       Polls cursor, draws yellow hover square
    anchor-watch.ts     Watches border pixels; fires re-calibration on resize/move
    dot-hover.ts        UnlockHoverFlow — gold-dot refresh + hover-to-unlock wiki pipeline
    ge-debug.ts         GE interface detection + debug overlays
    overlay.ts          RS overlay drawing (drawDetectDebug, debugFindSlot, drawSlotHover, etc.)
    tooltip-read.ts     TooltipScanner + readTooltipItemName — tooltip border scan + OCR
    wiki.ts             RuneScape wiki API — fetchItemTradeable, pickImageForQuantity
    backup.ts           Backup/restore unlock DB to/from gzipped JSON
  ui/
    ui.ts               DOM rendering + UI action handlers
    modal.ts             Confirm dialog
    recent-unlocks.ts    Ring buffer of recently unlocked items
    manual-unlock.ts     Manual item unlock flow
    gold-dot.ts          Gold dot overlay asset + draw position
```

## Rules

- Don't commit unless the user explicitly asks you to commit.
- New code goes in the file that owns its concern. If no file owns it, create one.
- `index.ts` only imports + bootstraps + re-exports. Never dump logic there.
- HTML buttons use `onclick="Bronzeman.fn(...)"`. Those fns are re-exported by index.ts.
- Dependency direction: `core` ← `data`/`inventory`/`detect` ← `ui`/`overlay`/`modal` ← `capture` ← `index`
- All shared interfaces/types live in `types/index.ts` — import from there, re-export where needed.
- Pure helper functions live in `utils/helpers.ts` (no DOM, no state, no side effects).
- Classes (Inventory, InventorySlot, SlotLoadingAnimation) live in `classes/`.
- Orchestration modules (singletons, timers, polling loops) live in `services/`.
- DOM rendering and UI interaction handlers live in `ui/`.
- Never use `any` — prefer `unknown` with type guards/narrowing.
